# Olivae 🌿✈️

> A simple and elegant travel planning landing page designed to help you organize your next adventure.

## 📖 About the project

Olivae is a travel planning landing page created as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

The idea behind Olivae is to create a simple travel companion where users can organize their flights, accommodations, activities and itineraries in one place.

This project was built from scratch to practice fundamental HTML and CSS concepts, with a focus on layout, Flexbox, visual hierarchy and responsive design.
