# Olivae 🌿✈️

> A simple and elegant travel planning landing page designed to help you organize your next adventure.

## 📖 About the project

The idea behind Olivae is to create a simple travel companion where users can compare their flights, accommodations, activities and create itineraries in one place.

This project was built from scratch to practice fundamental HTML and CSS concepts, with a focus on layout, Flexbox and visual hierarchy.

## 🎨 Design

Olivae's visual identity is inspired by the Mediterranean, combining warm neutral tones with deep olive green to create a calm and elegant aesthetic.

The project was designed with simplicity and usability in mind, keeping the interface clean while maintaining a strong visual identity.

## 🚧 Development status

Olivae is actively under development.

The current version focuses mainly on HTML and CSS fundamentals. The project will evolve alongside my progress through The Odin Project curriculum.

My goal is to gradually introduce new concepts and technologies rather than building the entire application at once.
